# Datasets

The synthetic workloads need **no downloaded files**; the real-world datasets are
large and are **not** bundled with this repository. This file explains how to obtain
or generate each one. Every method reads points from a whitespace-separated
coordinate file (one point per line, the first `dim` columns used) supplied through
the `RDF_INPUT` environment variable — except the Uniform control, which the binary
generates internally.

## Synthetic

| Workload | How to obtain |
|----------|---------------|
| **Uniform** | Generated by `acs` itself (fixed seed). Just pass `num_points`; do **not** set `RDF_INPUT`. |
| **Normal** (σ = 0.05, 0.1, 0.2) | Generate with `scripts/gen_normal.py`, then feed via `RDF_INPUT`. |

```bash
# Uniform, 1e6 points, 3D — no file needed:
./acs 1000000 0.2 1 0.1 ring 1 --dim 3 --force-binsearch

# Normal, sigma=0.1, 1e6 points, 3D:
python3 scripts/gen_normal.py --n 1000000 --dim 3 --sigma 0.1 \
        --out data/normal_3d_sigma0.1.xyz
RDF_INPUT=data/normal_3d_sigma0.1.xyz ./acs 1000000 0.2 1 0.1 ring 1 --dim 3 --force-binsearch
```

## Real-world

All three are public or author-generated; convert each to a plain coordinate file
(`.xy` for 2D, `.xyz` for 3D), then pass via `RDF_INPUT`. The binary rescales any
input to the unit cube, so only the relative geometry matters.

### GeoNames (2D, ~1.3e7 points)
Geographic coordinates from the global GeoNames gazetteer.
- Download `allCountries.zip` from <https://download.geonames.org/export/dump/>.
- Extract longitude (col 6) and latitude (col 5) into two whitespace-separated
  columns, e.g.:
  ```bash
  unzip -p allCountries.zip allCountries.txt \
    | awk -F'\t' '{print $6, $5}' > data/geonames.xy
  ```

### TIGER (2D, ~1.5e7 points)
US road-network vertices from the 2024 Census TIGER/Line release.
- Download the 2024 "Roads" shapefiles from
  <https://www.census.gov/geographies/mapping-files/time-series/geo/tiger-line-file.html>.
- Extract vertex coordinates (e.g. with GDAL/ogr2ogr or pyshp) into two columns
  `lon lat` -> `data/tiger.xy`.

### Ar vapor MD (3D, 4e6 points)
A molecular-dynamics snapshot of argon vapor, generated by the authors with LAMMPS
(Lennard-Jones argon), stored as `x y z` per line. The exact 4M snapshot used in the
paper is **available from the authors on request** (open an issue on this repository
or contact the authors listed in the paper). To regenerate instead, run an LJ argon
vapor simulation in LAMMPS and dump atom coordinates, keeping the `x y z` columns,
then feed the file via `RDF_INPUT`.

> Note: the large coordinate files are intentionally kept out of git to avoid
> bloating the repository. Request the exact files used in the paper from the authors,
> or reproduce them with the sources above.
